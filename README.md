# IndiePass

An open social app with support for [IndieWeb](https://indieweb.org/), [Mastodon](https://joinmastodon.org/), [Pleroma](https://pleroma.social/), and [Pixelfed](https://pixelfed.org/).

## About

IndiePass is a free and open-source social media client that lets you connect with multiple platforms from a single app. Whether you're part of the IndieWeb community with your own website, or prefer federated social networks like Mastodon, Pleroma, or Pixelfed, IndiePass brings everything together in one place.

## Key Features

- **Multi-account support**: Login with multiple domains and account types
- **IndieWeb integration**: Discover and use IndieAuth, Micropub, Microsub, and media endpoints with PKCE support
- **Fediverse support**: Connect to Mastodon, Pleroma, and Pixelfed instances
- **Rich posting options**: Create articles, notes, replies, reposts, likes, bookmarks, events, and more
- **Media support**: Add images, videos, and audio with filters, text, and emoji overlays
- **Built-in reader**: Browse channels, manage feeds, and enjoy offline reading
- **Location sharing**: Add geolocation to posts, check-ins, and venues
- **Share intents**: Quickly share text and images from other apps
